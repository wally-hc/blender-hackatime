# Blender Hackatime

Tracks the time you spend in Blender on [Hackatime](https://hackatime.hackclub.com). Based on [Godot Super-Wakatime](https://github.com/BudzioT/Godot_Super-Wakatime).

Although built for Hackatime, it works with any WakaTime server. Needs Blender 4.2 or newer.

## Install

1. Download the zip from the [latest release](https://github.com/wally-hc/blender-hackatime/releases/latest).
2. In Blender, open **Edit → Preferences → Get Extensions**, choose **Install from Disk** in the top-right menu and pick the zip.
3. Open the add-on's preferences and click **Set Hackatime API Key**. Skip this if `~/.wakatime.cfg` already has your key.
